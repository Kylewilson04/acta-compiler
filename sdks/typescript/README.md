# `@acta/sdk` (TypeScript / Zero-Dependency ESM)

Official Node.js / TypeScript SDK, offline RFC 8785 JCS ([`serde_jcs`](https://docs.rs/serde_jcs/latest/src/serde_jcs/lib.rs.html)) + BLAKE3 + strict Ed25519 ([`ed25519-dalek`](https://docs.rs/ed25519-dalek/latest/ed25519_dalek/struct.VerifyingKey.html)) verifier, and [`@google/genai`](https://www.npmjs.com/package/@google/genai) pre-prompt guard for [Acta Compiler](https://acta-server-998422936041.us-west1.run.app/).
